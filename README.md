# The Language of AI

Take-home kit from the workshop **The Language of AI: Communicating to Non-Technical Audiences**, facilitated by Chandra Pandiripalli.

## Start here: [open the kit](ai-brief-kit/README.md)

The kit teaches three skills, all in plain language:

1. **Talking about AI:** explain any AI project in four sentences and under 30 seconds.
2. **Talking to AI:** a 5-part prompt that gets better answers from any AI assistant.
3. **Where to draw the line:** seven questions to ask before you use or buy an AI tool.
